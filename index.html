Community AI Node 0.1

A locally governed accessibility intelligence prototype.

Build from the street outward.

Community AI begins with people, place, access needs, and governance—not with a model looking for somewhere to be deployed.

person → street → community → need → system → infrastructure

Access state

A(t) = [m, p, r, s, c, l, e, g]
m
Mobility and path access
p
Pace and timing access
r
Reach and physical interaction
s
Sensory and perceptual access
c
Cognitive-load access
l
Language and communication access
e
Environmental access
g
Agency, consent, and control

Participation objective

x*(t) = arg max_x E[ Participation(x | A(t), E(t)) ]

The prototype chooses the action most likely to increase meaningful participation under the current access and environmental conditions.

Governance gates

Access(x) ≥ τA
Privacy(x) ≥ τP
Agency(x) ≥ τG
The optimization target is participation, not classification.

Node 0.1

The first version is software: a deterministic access-state model, participation scorer, and governance gate. A local open-weight language model can be added later as an interface—not as the source of the governance rules.

This repository is currently in active prototype development.
